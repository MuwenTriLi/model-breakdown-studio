# A reusable model-presentation workflow

[← Model Breakdown Studio](../README.md) · [All projects](https://github.com/MuwenTriLi/creative-workflows#selected-work)

**Input:** a model with named, separate meshes and a presentation goal.
**Output:** an exploded view, timed component reveal, and a locally rendered MP4 or still.

1. Inspect the hierarchy and correct orientation before composing motion.
2. Decide which components explain the design. Hide distractions and select one focal part.
3. Use a restrained explode amount and safe frame. Preserve the spatial relationship of adjacent parts.
4. Place components manually only when the layout improves the explanation. Record layout keyframes with K.
5. Add highlight/reveal cues in a logical sequence. Give each important component enough time to read.
6. Preview the full sequence. Check overlaps, labels, framing and the return to the assembled state.
7. Export a short 720p proof, inspect it, then choose a higher resolution if needed.

The application implements these interactions. This document describes the repeatable procedure. An agent Skill could later wrap model preparation, preset selection and output review, but no automated agent integration or tested SKILL.md is claimed here.
