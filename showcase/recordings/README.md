# Screen recording — awaiting material

Suggested sequence: import a model → inspect parts → change explode/highlight → preview motion → show the result.

A focused recording of roughly 45–90 seconds is sufficient; use the duration that makes the interaction understandable. Keep button labels and cursor actions readable. A 16:9 MP4 at 1080p is a practical starting point.

Send the recording in chat or provide its local file path. Keep the original recording untouched; a separate viewing copy can be prepared and placed here after review. Large originals should remain outside the repository; an approved shorter clip or video link can be used for the case study.
