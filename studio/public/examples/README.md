# Model Breakdown Studio examples

Three GLBs supplied by Muwen Li for the public interactive portfolio demonstration:

| Model | Mesh parts | Delivery download |
| --- | ---: | ---: |
| Wood House | 18 | 0.1 MB |
| Press Manufacturing Line | 32 | 5.6 MB |
| Car Production Line | 30 | 14.7 MB |

The `.glb.gz` assets use lossless gzip. Decoding restores the supplied GLB bytes exactly; no geometry, names, hierarchy or materials were simplified. Thumbnails are captures of those models in the application. These examples are presentation media, excluded from the code's MIT license; no additional model redistribution license is granted here. Rights remain with their respective owners.

Visitor imports are read and processed in the browser. Selecting another example replaces the current model and clears its part edits and timeline after confirmation. Export work before switching.
